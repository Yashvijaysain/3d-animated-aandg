# 3d-animated-aandg

A&G Realtors luxury real estate website built with Next.js, TypeScript, GSAP, ScrollTrigger and Lenis.

## Features

- Premium animated A&G home page
- Curated project discovery page
- County Group project detail pages
- Responsive project gallery
- Contact section with A&G business details
- SEO metadata for A&G Realtors and Delhi-NCR luxury real estate keywords

## Scripts

```bash
npm run dev
npm run lint
npm run build
```
